## 注文 JSON ファイルの説明

| キー   | 内容       | 型                                    |
| ------ | ---------- | ------------------------------------- |
| date   | 注文日     | str(YY-MM-DD)                         |
| due    | 注文締切日 | str(YY-MM-DD)または以下表のキーワード |
| code   | 銘柄コード | str                                   |
| type   | 売買種別   | str                                   |
| value  | 買値/売値  | int                                   |
| volume | 株数       | int                                   |

### due

| 値  | 内容                             |
| --- | -------------------------------- |
| max | 想定期間の最大までを締切日とする |

### type

| 値         | 内容                                                 |
| ---------- | ---------------------------------------------------- |
| buy        | 買い                                                 |
| sell       | 売り                                                 |
| buy-open   | 始値で買う。value の値は無視される                   |
| sell-delta | value で指定した分だけ買値よりも高い値になったら売る |

### volume

| 値 | 内容 |
| 0 以上 | 指定した株数を買う/売る |
| 0 未満 | 買付可能額が許す限りの株数を買う/保持している株数全てを売る |
